# Bitter Habits

A habit tracker for Bitter. Android, dark theme, with a home-screen widget.

- Add as many habits as you like, each with an emblem and one of five neon colours
- Every day (with optional planned rest days) or X times a week
- A Monday-to-Sunday week that's fully done or rested turns into one squiggle
- Week and month views, streaks, perfect-week count, optional bitterness rating
- Reminders (off by default), archive, reorder, backup and restore
- Resizable, scrollable widget showing the current week

## Download

**https://github.com/YOUR-USERNAME/bitter-habits/releases/latest/download/BitterHabits.apk**

This link always gives the newest version. To update, open the same link and install over the old app.
Your habits and history are kept.

First time on Android: when asked, allow your browser to "install unknown apps".

## Building locally (optional)

Open the folder in Android Studio and run, or use `gradle assembleRelease` with Gradle 8.11+ and JDK 17.
